# Smart College Placement Portal

## Project Overview

The Smart College Placement Portal is a web-based application developed to simplify and organize the college placement process. It provides a centralized platform where students can explore job opportunities and submit applications, while administrators can manage job postings and review applications.

This project was developed as part of my hands-on learning journey to strengthen my understanding of Python-based web applications, backend development, and database integration.

**Project Status:** Core functionality implemented; further enhancements are in progress.

## Key Features

- **Student Authentication:** Student registration and login.
- **Student Dashboard:** Access to available job opportunities and application information.
- **Admin Dashboard:** Administrative access to manage placement activities.
- **Job Management:** Create and manage job postings.
- **Application Management:** Review student applications and update their status.
- **Candidate Selection:** Select or reject applicants.
- **Database Integration:** Store and manage application data.
- **Session Management:** Manage user sessions and protect relevant application pages.

## Technologies Used

- **Programming Language:** Python
- **Web Framework:** Flask
- **Database:** SQLite
- **ORM:** SQLAlchemy
- **Frontend:** HTML, CSS, Bootstrap

## Application Workflow

1. Students register and log in to the portal.
2. Students explore available job opportunities.
3. Students submit applications for suitable positions.
4. Administrators manage job postings and review applications.
5. Administrators update application statuses based on their decisions.

## Project Structure

The project uses a Flask application structure with templates for the user interface and a SQLite database for persistent data storage.
